# Rock Band Landing Page

## Description

This is a landing page for a rock band.

The page promotes the band, its music style, and its next events.

The design uses dark colors, red details, images, cards, and a simple table.

The objective of this project is to practice HTML5, CSS3 and JAVASCRIPT.

## Technologies Used

- HTML5
- CSS3
- JAVASCRIPT
